# ADR 0002 — Answers to the planning questions

- Status: Accepted
- Date: 2026-11-10

| #   | Topic                | Decision                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Name & license       | Product **GameX Engine**. npm scope `@gamex/*`, CLI `gamex`, Spec Pack folder `gamex/` in target repos, env vars `GAMEX_*`, generated-file header `GENERATED BY GAMEX ENGINE`. License **Apache-2.0**. (`docs/MASTER_PROMPT.md` is kept verbatim as the historical brief; "GameSpec" there means GameX Engine.)                                                                                                              |
| 2   | IDs & expressions    | kebab-case `id` + derived camelCase `key`. Expressions are strings over `key`s, parsed to an AST.                                                                                                                                                                                                                                                                                                                            |
| 3   | Numbers              | Byte-identical results in every JS runtime: integer resources, declared curve rounding, only exactly-specified float ops plus tested in-house `log`/`exp`. A seed can be shared with anyone.                                                                                                                                                                                                                                 |
| 4   | Review & work files  | Committed `gamex/review.json` ledger (approve/edit/reject shared by the team). Bulky intermediates (chunks, raw AI output, run results) in git-ignored `gamex/.work/`. `game-model.json` holds only approved items.                                                                                                                                                                                                          |
| 5   | Studio               | `gamex studio` local server: localhost only, per-launch token, serves the UI, reads/writes the repo safely, makes AI calls server-side. Plus a static offline build (import model file, download Spec Pack as zip, no extraction).                                                                                                                                                                                           |
| 6   | Reference runner     | Zero-dependency TypeScript, run with plain `node` ≥ 22.18 (native type stripping).                                                                                                                                                                                                                                                                                                                                           |
| 7   | Swarm Rescue screens | Proposed 22-state list (S00 Loading … S21 Pause), every item `assumed`.                                                                                                                                                                                                                                                                                                                                                      |
| 8   | Gameplay model       | **Two-level mission model.** Level 1 weighted `outcomes` always present (stable contract). Level 2 optional per-mission `combat` block (waves, boss, hero power from upgrade constants, persona skill, combo/near-miss multipliers) from which the engine derives outcome probabilities with a seeded wave-by-wave resolver. Built at the end of Phase 2. Reports label it a stylized model; combat numbers start `assumed`. |
| 9   | Revenue assumptions  | Optional. Revenue KPIs computed only when eCPM/fill-rate assumptions exist; placeholders are flagged as gaps and the user is asked for real numbers.                                                                                                                                                                                                                                                                         |
| 10  | LLM                  | User chooses the model/agent: `--model` → `GAMEX_MODEL` → `gamex/config.json` → default `claude-opus-5-5`. Providers: Anthropic API, and an agent-handoff provider that lets the user's own coding-agent session fill extraction requests. Only confirmed files are sent; no telemetry; optional `--budget` token cap.                                                                                                       |

## Consequences

- Schema gains an optional `combat` section and an optional `monetization.assumptions`.
- Phase 2 grows by about one session (combat resolver) and Phase 4 by the handoff provider.
